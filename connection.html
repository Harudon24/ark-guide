サーバー接続手順

ASAではSteamの「ゲームサーバー」にIPを登録して接続するのではなく、ゲーム内の非公式サーバー一覧から検索して接続します。

SERVER NAME
Ark #12068 hosted by Harudon
検索欄には Harudon と入力すれば見つけやすいです。
SERVER ADDRESS
45.140.129.27:6490
IP: 45.140.129.27 / ゲームポート: 6490
IPアドレスは確認用。 ASAへの参加はゲーム内の「非公式」サーバー検索から行います。サーバー一覧に反映されていないときは「更新」を押します。
01

「ゲームに参加」を選ぶ

ARKを起動し、メインメニューから「ゲームに参加」を開きます。

メインメニューでは「ゲームに参加」を選択。
02

「非公式」を選んで検索

上部で「非公式」を選び、右上の検索欄に Harudon と入力します。下部の「パスワードありのサーバーを表示」にもチェックを入れます。表示されない場合は「更新」を押します。

非公式Harudonパスワードあり
赤枠の「非公式」「Harudon」「パスワードありのサーバーを表示」を確認。
03

サーバーを選んで「開始」

一覧に表示された Ark #12068 hosted by Harudon を選択し、右下の「開始」を押します。

04

必要に応じてMODをインストール

未導入のMODがある場合は、参加前に「必要なMOD」画面が表示されます。表示されたMODをダウンロード・インストールしてから進みます。すべて「インストール済み」で「ダウンロードするMOD: 0」なら、そのまま「開始」でOKです。

必要なMODが表示されたら、ダウンロード・インストールしてから「開始」を選択。
05

パスワードを入力して接続

サーバーパスワードを求められたら入力して接続します。初回はMODのダウンロードや準備で少し時間がかかる場合があります。
