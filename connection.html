ARK: SURVIVAL ASCENDED / NITRADO

サーバー接続手順

ASAではSteamの「ゲームサーバー」にIPを登録して直接接続する方式は使いません。ゲーム内の非公式サーバー一覧から検索して接続します。

SERVER NAME
Ark #12068 hosted by Harudon
検索は Harudon など名前の一部でOK。
SERVER ADDRESS
45.140.129.27:6490
IP: 45.140.129.27 / ゲームポート: 6490
IPアドレスは確認用。 ASAへの参加はゲーム内の「非公式」サーバー検索から行います。サーバー名を変更した直後は「更新」を押すと新しい名前が反映されます。
01

「ゲームに参加」を選ぶ

ARK: Survival Ascendedを起動し、メインメニューから「ゲームに参加」を開きます。

参考画像：送ってもらった画面の右側（ARK部分）だけを使用。
02

「非公式」を選んで検索

上部で「非公式」を選び、右上の検索欄に Harudon と入力します。下部の「パスワードありのサーバーを表示」にチェックを入れて、必要なら「更新」を押します。

非公式Harudonパスワードあり
赤枠の「非公式」「Harudon」「パスワードありのサーバーを表示」を確認。
03

サーバーを選んで「開始」

一覧から「Ark #12068 hosted by Harudon」を選択して右下の「開始」を押します。

04

必要に応じてMODをインストール

未導入のMODがある場合は参加前に「必要なMOD」画面が出ます。表示されたMODをダウンロード・インストールしてから進みます。すべて「インストール済み」で「ダウンロードするMOD: 0」なら、そのまま「開始」でOKです。

現在のサーバーでは Visual Storage / Super Spyglass Plus / Configurable Cryopods の3つを使用。
05

パスワードを入力して接続

サーバーパスワードを求められたら入力して接続します。初回はMODの準備などで少し時間がかかる場合があります。
