ARK: SURVIVAL ASCENDED / NITRADO

サーバー接続手順

ASAではSteamの「ゲームサーバー」にIPを登録して直接接続する方式は使いません。ゲーム内の非公式サーバー一覧から検索して接続します。

SERVER NAME
Ark #12068 hosted by Harudon
検索するときは Harudon など名前の一部でOKです。
SERVER ADDRESS
45.140.129.27:6490
IP: 45.140.129.27 / ゲームポート: 6490
IPアドレスは確認用。 ASAへの参加はゲーム内の「非公式」サーバー検索から行います。サーバー名を変更した直後は、一覧画面の「更新」を押すと新しい名前が反映されます。
01

「ゲームに参加」を選ぶ

ARK: Survival Ascendedを起動し、メインメニューから「ゲームに参加」を開きます。

参考画像：右側のARK画面のみを使用しています。
02

「非公式」を選んでサーバーを検索

上部で「非公式」を選び、右上の検索欄に Harudon などサーバー名の一部を入力します。下部の「パスワードありのサーバーを表示」にもチェックを入れて、必要なら「更新」を押します。

非公式Harudonパスワードあり
この状態で「Ark #12068 hosted by Harudon」が表示されればOK。
03

サーバーを選んで「開始」

一覧から「Ark #12068 hosted by Harudon」を選択し、右下の「開始」を押します。

04

必要に応じてMODをインストール

サーバーで使用しているMODが未インストールの場合は、参加前に「必要なMOD」画面が表示されます。表示されたMODをダウンロード・インストールしてから進みます。すでに入っていれば「インストール済み」と表示され、そのまま開始できます。

現在のサーバーでは Visual Storage / Super Spyglass Plus / Configurable Cryopods を使用。
05

パスワードを入力して接続

サーバーパスワードを求められたら入力して接続します。初回はMODの準備などで少し時間がかかる場合があります。
