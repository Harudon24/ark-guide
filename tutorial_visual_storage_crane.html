Crane の使い方

採取に使った恐竜などから資源をまとめて降ろし、そのままVisual Storageへ振り分けるための機能です。Dropboxよりさらに自動化できます。

荷下ろし範囲やDistributionの設定が必要です。基本収納だけでも困らないので、分からなければCraneは無理に使わなくてもOKです。
最初は恐竜1体・資源1種類で試す： 石20個だけを持たせた恐竜1体で「Craneへ降ろす → Stone Binへ送る」の流れを確認すると分かりやすいです。

何が便利？

Visual Storage公式説明では、Craneは恐竜・恐竜サドル・いかだ・カートなどから資源を荷下ろしでき、荷下ろし範囲を調整でき、複数の恐竜にも対応します。さらにDropboxと同じように、取り込んだ資源を選んだ収納へDistributionできます。

PCで試す：恐竜の石20個をStone Binへ送る

画面名やボタン名はMODのバージョン・言語設定によって多少変わる可能性があります。まずは1体で成功させてから対象を増やしてください。

01

CraneとStone Binを用意する

Craneを製作して、恐竜が近づける場所へ設置します。近くに空き容量のあるStone Binも用意します。

最初のテストでは、関係ない恐竜はCraneから少し離しておくと、どの恐竜が対象になったか確認しやすくなります。

02

荷下ろし範囲を確認する

Craneに照準を合わせ、E長押しのオプションメニューから設定画面を開きます。公式ギャラリーではCraneの荷下ろし範囲を表示して調整する画面が公開されています。

Unload Area / Show Areaのような項目が表示されたら範囲を可視化し、恐竜が入る大きさに調整します。サイズを変更した場合は保存操作まで行います。

03

恐竜に石20個を持たせて範囲内へ移動する

テスト用の恐竜のインベントリに石20個を入れ、Craneの荷下ろし範囲内へ移動させます。

公式仕様では、恐竜側のvsという名前のフォルダー内に入れたアイテムはCraneの荷下ろし対象から除外されます。残しておきたい物がある場合に使えます。

04

Craneから荷下ろしを実行する

Craneを開き、恐竜をUnloadする操作を実行します。成功すると、対象資源が恐竜から減り、Crane側へ移ります。

この時点ではまだStone Binまで送られていない場合があります。まず「恐竜 → Crane」が成功したかを確認します。

05

Stoneの送り先をStone Binに設定する

CraneのDistribution設定を開き、Stone → Stone Binになるよう送り先を登録します。保存操作がある場合は設定を保存します。

Dropboxで同じDistribution設定を済ませている場合、公式説明では範囲内のDropboxとCrane間で設定が同期されることがあります。実際の送り先がStone Binになっているかだけは確認してください。

06

Distributionを実行して3か所を確認する

Crane内の石をDistributionし、Stone BinをFで開きます。他の出し入れや容量不足がなければ、石20個がStone Binへ移ります。

恐竜 → Crane → Stone Binの順に確認すると、失敗した場所を切り分けやすくなります。

試す例： 恐竜の通常欄に石20個、vsフォルダーに木材5個を入れる → Craneの範囲内でUnload → 石20個はCraneへ移り、木材5個は恐竜に残ることを確認 → 石をDistributionしてStone Binへ送る。これで「回収する物」と「残す物」の両方を確認できます。

慣れてきたら

  • 複数の恐竜： Craneは複数の恐竜を同時に荷下ろしできます。1体で成功してから範囲内の対象を増やすのがおすすめです。
  • 範囲調整： 荷下ろし範囲を広げすぎると、意図していない恐竜まで対象になりやすくなります。見える範囲で必要な大きさにします。
  • Dropboxと同じDistribution： Craneは荷下ろしたあと、Dropboxと同様に選んだVisual Storageへ資源を振り分けられます。
  • Remote Lever： 公式説明ではDino unload crane and remote leverも用意されています。まずCrane本体で動作を確認してから使うと分かりやすいです。

うまくいかないとき

  • 恐竜が荷下ろし範囲の中にいるか確認する。
  • 恐竜の資源がvsフォルダーに入っていないか確認する。
  • Crane側に資源が移っているなら、次はDistribution設定と送り先容量を確認する。
  • Crane側にも移っていないなら、荷下ろし範囲・対象資源・恐竜の位置を確認する。
  • 一度に大量の恐竜・大量の資源で試さず、1体・少量から確認する。
