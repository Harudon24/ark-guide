ASA / Performance

ゲームを軽くする

ASAのコンソールを有効にして、負荷の高い描画を減らす手順です。まずは雲と霧だけをOFFにして、見た目を残しながらFPSがどれくらい変わるか確認します。

管理者権限不要自分のPCだけに反映サーバー設定には影響しない
STEP 1

コンソールを使えるようにする

最初に1回だけ設定します。

01
ESC → 設定
ゲーム内の設定画面を開く
02
「詳細」を開く
「コンソールアクセス」をON
03
キーボードを確認
「コンソールの切り替え」のキーを確認
04
~ で開く
割り当てを変えている場合は設定したキーを使用
ここで使うのはクライアント側の描画設定です。 NitradoのAdmin Passwordや enablecheats は不要です。
STEP 2

コンソールを開いて入力する

画面下の入力欄にコマンドを貼り付けて実行します。上側には入力したコマンドの履歴が表示されます。

STEP 3

まずは雲・霧をOFF

見た目を大きく壊しにくいものから順番に試します。

RECOMMENDED

雲 + 霧をOFF

まずはこれ。ASAで負荷の高いボリューメトリック描画を切ります。

r.VolumetricCloud 0 | r.VolumetricFog 0
MORE FPS

水面反射もOFF

まだ重い場合に追加。草は残すので、景観を大きく変えずにもう少し軽量化できます。

r.VolumetricCloud 0 | r.VolumetricFog 0 | r.Water.SingleLayer.Reflection 0
LAST RESORT

草をOFF — 最終手段

かなり殺風景になります。 それでも重い場合だけ使用する想定です。

grass.Enable 0
COMMANDS

コマンドごとの効果

一気に全部切らず、1つずつ試して見た目とFPSのバランスを調整できます。

雲をOFF
ボリューメトリッククラウドを無効化。軽量化コマンドの中でも効果が大きい定番。
r.VolumetricCloud 0
戻す: r.VolumetricCloud 1
効果 大
霧をOFF
ボリューメトリックフォグを無効化。遠景の雰囲気は変わりますが負荷軽減に有効です。
r.VolumetricFog 0
戻す: r.VolumetricFog 1
効果 大
水面反射をOFF
水面の反射表現を減らして軽量化します。
r.Water.SingleLayer.Reflection 0
戻す: r.Water.SingleLayer.Reflection 1
効果 中
草をOFF
草などの植生を消します。かなり軽くなる可能性がありますが、景観が大きく変わって殺風景になるため最終手段。
grass.Enable 0
戻す: grass.Enable 1
最終手段
CHECK

FPSを確認する

FPS表示

設定変更前後を同じ場所で比べると分かりやすいです。

stat fps

おすすめの順番

① 雲・霧 → ② 水面反射 → ③ それでも重ければ草。必要以上に画質を落とさないようにします。

注意： コンソールによる描画変更は、ゲーム再起動などで元に戻る場合があります。戻った場合はもう一度入力してください。
