ASA / Performance

ゲームを軽くする

ASAのコンソールを有効にして、負荷の高い描画をOFFにする手順です。まずは雲と霧だけをOFFにして、FPSがどれくらい変わるか確認するのがおすすめです。

管理者権限不要 各自PCだけに反映 サーバー設定には影響しない
STEP 1

コンソールを使えるようにする

最初に1回だけ設定します。キーは変更できるので、実際の割り当ても確認しておくと確実です。

01
ESC → 設定
ゲーム内の設定画面を開く
02
詳細設定
「コンソールへのアクセス」をON
03
キーボード
「コンソールの切り替え」のキーを確認
04
~ で開く
初期キー。変更済みなら設定したキーを使用
ここで使う軽量化コマンドはチートではありません。 クライアント側の描画設定を変更するだけなので、NitradoのAdmin Passwordや enablecheats は不要です。
STEP 2

まずはこれだけ

見た目を大きく壊しにくく、効果を感じやすい2項目から試します。

RECOMMENDED

雲 + 霧をOFF

ASAで特に重いボリューメトリック描画を切ります。まずはこの状態でプレイして問題なければそのままでOK。

r.VolumetricCloud 0 | r.VolumetricFog 0
MORE FPS

さらに軽くする

雲・霧に加えて草と水面反射もOFF。軽くなりやすい代わりに、見た目の変化はかなり分かりやすくなります。

r.VolumetricCloud 0 | r.VolumetricFog 0 | grass.Enable 0 | r.Water.SingleLayer.Reflection 0
COMMANDS

コマンドごとの効果

一気に全部切らず、1つずつ試して見た目とFPSのバランスを調整できます。

雲をOFF
ボリューメトリッククラウドを無効化。軽量化コマンドの中でも効果が大きい定番。
r.VolumetricCloud 0
戻す: r.VolumetricCloud 1
効果 大
霧をOFF
ボリューメトリックフォグを無効化。場所や天候によって負荷軽減が分かりやすい。
r.VolumetricFog 0
戻す: r.VolumetricFog 1
効果 中
草をOFF
地面の草を非表示にするためかなり軽くなりやすい。景色の変化も大きいので必要な場合だけ。
grass.Enable 0
戻す: grass.Enable 1
効果 大
水面反射をOFF
水面の反射表現を無効化。雲や草ほど大きくはないものの、海や川の近くで少し軽くできます。
r.Water.SingleLayer.Reflection 0
戻す: r.Water.SingleLayer.Reflection 1
効果 小〜中
CHECK

軽くなったか確認する

同じ場所でコマンドの前後を比べると効果が分かりやすいです。

FPSを表示

画面に現在のFPSを表示します。同じコマンドをもう一度実行するとOFFになります。

stat fps

おすすめの試し方

① FPS確認 → ② 雲+霧をOFF → ③ FPS確認 → ④ 必要なら草・水面反射もOFF、の順に試します。

ゲームを再起動すると戻る場合があります。 軽量化が解除されていたらコンソールから再実行してください。入力履歴が表示されている場合は、履歴から選べば打ち直す必要はありません。
