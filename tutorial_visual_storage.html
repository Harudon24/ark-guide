Visual Storage の使い方

Visual Storageは、資源ごとの専用収納を追加し、中に入っている量に合わせて見た目も変化する収納MODです。資源整理だけでなく、拠点内のアイテム移動やクラフトも楽にできます。

まず覚えること： Visual Storageに入れた資源は、対応するクラフトでは自分の手持ちや作業台へ毎回移し直さなくても、Wireless Craftingの資源元として利用できます。 たとえば木材をWood用収納へ入れておけば、設定された範囲内ではその木材がクラフト用の資源として使われます。Wireless Craftingの有効範囲などはサーバー設定によって変わります。

木材で覚える：習得 → 作成 → 設置 → 収納 → 取り出し

最初は「木材」を例に一連の流れを覚えるのがおすすめです。Visual Storageでは1つの収納エングラムに複数の資源バリエーションが用意されており、今回はWoodを使います。

01

「BIN - VS」のエングラムを習得する

エングラム画面を開き、検索欄に VS と入力して「BIN - VS」を探します。BIN - VSにはFiber・Metal・Stone・Thatch・Woodなどのバリエーションがあり、今回はWoodを使います。

02

BIN - VSを作る

習得したBIN - VSを選び、必要素材をそろえて作成します。WoodはBIN - VSのバリエーションの1つです。

撮ってほしいスクショ： BIN - VSを選択した製作画面。アイテム名・必要素材・製作ボタンが同時に見える状態が理想です。
03

Woodに切り替えて設置する

BIN - VSをホットバーから選び、設置プレビュー中に R でバリエーションを切り替えて Wood を選びます。Woodになっていることを確認してから、使いやすい場所に設置します。

撮ってほしいスクショ： 設置前のプレビュー状態で、Rでバリエーションを切り替えている画面。Woodが選ばれていることと、Rの操作表示が分かる状態。
撮ってほしいスクショ： 設置後のWood用収納が全体で見える画面。できれば中身が空の状態で、あとから木材を入れた状態と比較できるようにします。
04

木材を入れる

Wood用収納を開き、手持ちの木材を収納へ移します。入れた数量は収納側に保存され、中身の量に応じてVisual Storageの見た目も変化します。

撮ってほしいスクショ： Wood用収納のインベントリを開き、木材の数量が確認できる画面。可能なら木材を入れた後の収納本体も別に1枚撮ってください。
05

収納した木材をそのままクラフトに使う

Wireless Craftingの範囲内では、Visual Storageに入っている木材をクラフト用の資源元として利用できます。対応するクラフトなら、木材を自分のインベントリや作業台へ移し直さなくても、収納されている分が資源として反映されます。製作画面では、必要素材のWoodに表示される（ ）内の数値がVisual Storageに入っている分だけ増えるので、Wireless Craftingが効いているかを確認できます。

撮ってほしいスクショ： 自分の手持ちや作業台に木材を入れていない状態で、木材を必要とするレシピが製作可能になっている画面。特にWoodの（ ）内の数値がVisual Storage分だけ増えていることが分かるように撮ってください。
06

必要な分だけ取り出す

Wood Binの中身を確認したいときは、収納に照準を合わせて F を押してインベントリを開きます。画面中央下部にある WITHDRAW ○ 木材 のボタンを押すと、表示されている数だけ木材を取り出せます。たとえば「WITHDRAW 5 木材」なら5個、「WITHDRAW 50 木材」なら50個を取り出します。WITHDRAW 木材 STACK (100) では1スタック（100個）を取り出せます。右側の数量欄に数値を入力して WITHDRAW を押せば、任意の数を指定して取り出すこともできます。

撮ってほしいスクショ： Wood BinをFで開き、画面中央下部のWITHDRAWボタンと、右側の数量指定欄・WITHDRAWボタンが見える状態。
木材で覚えたら： Stone・Thatch・Fiber・Metalなども同じ考え方で使えます。よく使う資源から少しずつ増やすと迷いません。

よく使う便利機能

木材で基本の流れを覚えたら、次はVisual Storageの便利機能を使うと資源整理がさらに楽になります。

おすすめ

Distribution

資源と収納先をリンクして、拠点内の指定した収納へまとめて振り分ける機能です。複数の収納やあふれたときの予備収納も設定できます。

クラフト向け

Wireless Crafting

Visual Storageをクラフト用の資源元として利用する機能です。対応するクラフトでは、収納から毎回資源を持ち出して自分や作業台へ入れ直さなくても、保存されている資源を利用できます。利用できる範囲は管理者設定で変更できます。

撮ってほしいスクショ： Distributionの設定画面。振り分け先の収納や対象資源が分かる状態。
撮ってほしいスクショ： Wireless Craftingが効いていることが分かる製作画面。手持ちに素材がない状態でVisual Storage内の素材が反映されていると分かりやすいです。
手持ちの資源を整理

Dropbox：持ち帰った木材・石を収納へ送る

Dropboxは資源をいったん受け取り、Distributionで決めた収納先へ送るための窓口です。まずは「木材 → Wood用収納」「石 → Stone用収納」の2種類だけで試しましょう。

操作表記について： 以下はPCの標準キー設定を想定しています。キーを変更している場合は自分の割り当てを使ってください。機能はCurseForgeの現行説明、英語の画面名・ボタン名は公開画像を参考にしています。画像は2024年のものを含むため、導入バージョンや表示言語によって名称・配置が異なる場合があります。ゲーム内での実機確認は未実施です。
01

Dropboxと送り先を用意する

エングラム検索で VS や Dropbox を使って対象を探し、画面に表示される必要素材をそろえて製作・設置します。近くにWood用とStone用の収納を置き、空き容量を確保します。最初は通常の地面・土台上の拠点で試すと、いかだ・プラットフォーム上の制限を切り分けやすくなります。

02

Fで開き、木材20個・石10個を入れる

Dropboxに近づいて照準を合わせ、F でインベントリを開きます。自分側の木材20個と石10個を、Dropbox側のアイテム欄へドラッグして移します。Dropbox側にアイコンと数量が出たことを確認してください。持ち物を全部移す前に、この少量で操作を覚えます。

03

Distributionの画面を開く

インベントリ内の DISTRIBUTION MENU をクリックします。公開画像では DROPBOX DISTRIBUTION という画面が開き、左に資源一覧、右に収納・設備の一覧が表示されます。左の検索欄で Wood を探して選び、右側で送り先のWood用収納を探します。

  • STRUCTURE： 送り先の収納・設備名。
  • QUANTITY： 数量の表示欄。実際に届いた数は、最後に収納本体を開いて確認します。
  • DISTRIBUTE： その送り先への振り分け設定。公開画像では緑／赤のアイコンで状態が表示されています。
  • RATIO： 複数の送り先へ分けるときの比率。最初は送り先を1つに絞ります。
04

木材と石の送り先を設定して保存する

Wood用収納の行にある DISTRIBUTE の設定を有効にします。Woodを送る先はその1つだけにし、比率欄が表示される場合はその収納へ100%送る設定にします。次に左側で Stone を選び、Stone用収納も同様に設定します。最後に SAVE ENTRIES をクリックして保存します。送り先が見当たらない場合は RE-SCAN で再検索し、距離・資源の種類・一覧のフィルターを確認してください。

05

インベントリへ戻り、振り分けを実行する

設定画面を閉じ、Dropboxのインベントリで DISTRIBUTE ALL をクリックします。これは設定済みの送り先へまとめて送る操作です。1種類ずつ試す場合は、Dropbox側で木材を選び DISTRIBUTE SELECTED を使います。設定の保存と資源の転送は分けて確認しましょう。

06

送り先を開いて、増えた数を確認する

Wood用収納とStone用収納をそれぞれFで開きます。送り先が空で、他の人の出し入れやクラフト消費がなく、全量を受け入れられた場合は、木材20個・石10個が入ります。Dropbox側の残量も確認し、残っていたらリンク設定・空き容量・対応資源を見直します。

試す例： Dropboxに木材20個・石10個を入れる → 木材を選んでDISTRIBUTE SELECTED → 木材だけがWood用収納へ移り、石10個はDropboxに残る → DISTRIBUTE ALL → 石もStone用収納へ移る、という順で確認します。送り先を正しく設定し、容量が足りる場合の確認例です。
  • 入れたのに届かない： まずDropboxに残っているかを確認します。資源ごとに送り先を登録・保存したか、DISTRIBUTE ALL／SELECTEDを実行したかを順に見直してください。
  • 別のDropboxにも同じ設定が出る： 範囲内のDropboxとCraneには設定同期機能があります。管理者が同期を無効にしている場合もあるため、実際の送り先一覧で確認します。
  • いかだ・サドル上で使う場合： 公開更新履歴では、同じいかだ・サドル上の構造物だけが振り分け先に表示され、設定同期も制限されると案内されています。陸上の収納が出ないときは、この設置場所の違いも確認してください。
確認資料（2026年9月7日）：作者の機能説明 ／ 作者公開のDistribution画面 ／ 同期・設置場所の更新履歴 ／ 転送ボタンの操作例（2024年）
恐竜の採取物を整理

Crane：恐竜の荷物を降ろして収納へ送る

Craneでは「恐竜からCraneへ荷下ろし」「Craneから収納へ振り分け」の順に確認します。荷下ろし範囲は調整でき、複数の恐竜にも対応しています。最初は恐竜1体と石20個だけで試しましょう。PCキーと公開画像の表記に関する注意はDropboxと同じです。

01

Craneと石の収納先を設置する

エングラム検索で VS や Crane を使って対象を探し、必要素材をそろえて製作・設置します。恐竜が近づける場所を選び、近くに空き容量のあるStone用収納を置きます。最初の確認では、荷下ろしを試さない恐竜は離しておきます。

02

設定画面で荷下ろし範囲を見えるようにする

Craneに照準を合わせ、E長押し の操作メニューから設定に相当する項目を探します。公開画像の設定画面名は CRANE SETTINGS MENU です。CRANE UNLOAD AREA を展開し、SHOW AREA をクリックして範囲を表示します。SizeのX・Y・Z が範囲調整欄で、変更した場合は SAVE SETTINGS で保存します。表示された範囲を見ながら、恐竜が収まるように調整してください。

注意： 同じ画面の STRUCTURE LOCATION AND ROTATION は構造物の位置・向きの設定です。荷下ろし範囲を調整するときはCRANE UNLOAD AREAを使います。設定への入口の名称・位置は導入版の表示を優先してください。

03

恐竜に石20個を持たせ、範囲内へ移動する

試す恐竜のインベントリへ石20個を入れ、表示した荷下ろし範囲内へ連れてきます。降りてからCraneを操作します。作者の説明では、恐竜側の vs という名前のフォルダーに入れたアイテムは荷下ろし対象から除外されます。残したい資源がある場合は、そのフォルダーへ移して少量で除外動作を確かめてください。

04

UNLOAD DINOでCraneへ荷下ろしする

Craneに照準を合わせて F でインベントリを開き、UNLOAD DINO に相当する荷下ろしボタンをクリックします。公開操作例では、恐竜の資源がCrane側のアイテム欄へ移ります。恐竜から石が減ったか、Craneに石が入ったかを確認します。この時点で収納先まで届いたとは判断せず、次の振り分けも確認してください。

05

Stoneの送り先を設定して転送する

Craneの DISTRIBUTION MENU を開き、左側のStoneに対して、右側のStone用収納を送り先に設定します。Dropboxと同じく DISTRIBUTE を有効にして SAVE ENTRIES で保存します。すでにDropboxから設定が同期されている場合も、目的の収納が選ばれているかを確認します。インベントリへ戻り DISTRIBUTE ALL、または石を選んで DISTRIBUTE SELECTED をクリックします。

06

恐竜・Crane・収納の3か所で結果を見る

Stone用収納をFで開き、石が20個増えたか確認します。ほかの出し入れがなく全量を転送できた場合、試した石は恐竜とCraneからなくなり、収納先へ移っています。Craneに残っているなら振り分け設定や容量、恐竜に残っているなら荷下ろし範囲・対応資源・vsフォルダーを確認します。

除外も試す例： 恐竜の通常のアイテム欄に石20個、vsフォルダーに木材5個を入れる → 範囲内でUNLOAD DINO → 石がCraneへ移り、木材5個は恐竜に残ることを確認 → DISTRIBUTE ALLで石をStone用収納へ送る。まずはこの少量で「降ろす物」と「残す物」を確認してから、採取帰りの荷物整理に使います。
  • 恐竜から何も移らない： SHOW AREAで表示した荷下ろし範囲へ恐竜を寄せ直します。収納への転送範囲と、恐竜の荷下ろし範囲は別に確認してください。
  • 一部の資源だけ残る： vsフォルダー内か、Craneが受け入れない資源か、容量不足かを確認します。何でも一括回収できるとは限りません。
  • 複数の恐竜から回収したい： 1体で成功してから、対象だけを範囲内へ増やします。近くの恐竜も対象になり得るため、表示範囲を見てから実行します。
  • 慣れてきたら： 作者は遠隔レバーも案内しています。まず本体で荷下ろしと振り分けができる状態にしてから導入すると、問題が起きた場所を確認しやすくなります。
確認資料（2026年9月7日）：作者のCrane・除外仕様 ／ 作者公開のCrane設定画面 ／ 荷下ろし・転送の操作例（2024年）

おすすめの使い方例

基本の流れが分かったら、拠点の規模に合わせて使う収納や便利機能を増やしていけばOKです。

序盤： 木材・石・わら・繊維など、使用頻度の高い資源だけ専用収納を作る。
中盤： 金属・水晶・黒曜石なども分けて、作業台や製錬設備の近くにまとめる。
採取後： DropboxやCraneに資源を集め、Distributionで各収納へ振り分ける。
クラフト拠点： Wireless Craftingを使って、Visual Storageに入れた資源をクラフトから直接利用できるようにする。

覚えておくと便利

  • 収納の見た目は、中に入っている資源量に合わせて変化します。
  • Wireless Craftingでは、対応するクラフトからVisual Storage内の資源を利用できます。
  • Wireless Craftingの範囲は管理者設定で10～100土台相当に変更できます。
  • 表示量は自動だけでなく、対応する収納では手動設定もできます。
  • 一部の収納は色やスタイルを変更できます。
  • スタックMODやARKの基本資源を継承したカスタム資源にも対応するとされています。
